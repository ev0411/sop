# 工作个人 Dashboard

这是一个根据需求文档生成的个人工作 Dashboard 静态网站原型。

## 功能范围

- 每周 To Do List 总表
- 全局搜索、分类、状态和交易方向筛选
- 手动新增、编辑、删除、完成/归档任务
- 文本自动分类并生成待确认任务
- 图片 OCR 与邮件读取的可演示入口
- 客户材料收集、缺失材料和逾期提醒
- 业务机会跟进与多进度标签展示
- 文件/合同、行政、市场营销、活动追踪模块
- 采购 Agent 示例结果与询价草稿
- 历史任务按周归档

## 使用方式

直接打开 `index.html` 即可使用。数据会保存在当前浏览器的 localStorage 中。

## 安全边界

系统只生成邮件、询价和采购草稿，不会自动发送邮件、询价或订单。客户证件、地址证明、资金来源等材料按高隐私级别处理。
